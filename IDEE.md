# Idee del progetto Buby Rent

File condiviso per annotare idee, proposte e miglioramenti. Chiunque lavori al
progetto può aggiungere una riga: non serve essere admin o CEO, basta una pull
request o un commit diretto sul branch concordato.

## Come si usa

1. Aggiungi **una riga in fondo alla tabella**, senza riscrivere le righe altrui.
2. Compila `Data` (`AAAA-MM-GG`), `Chi` (nome o iniziali), `Area`, `Idea`.
3. Lascia `Stato` su `nuova`; chi valuta la porta a `in valutazione`,
   `approvata`, `in corso`, `fatta` o `scartata`.
4. Se l'idea diventa lavoro vero, apri una voce nel backlog di `AGENTS.md` o una
   issue e metti il riferimento nella colonna `Idea`.
5. Niente dati personali, password, chiavi o segreti: questo file è versionato
   e pubblico nel repository. Per i dati reali valgono le regole GDPR del
   progetto.
